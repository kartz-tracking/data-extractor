Privacy

Extract Data, a Google Sheets add-on. Last updated 22 September 2026.

What the add-on can see

Only the spreadsheet it is installed in. It is authorised with Google's spreadsheets.currentonly permission, which gives it access to that one file and to no other file in your Google Drive. It also reads your email address, through the standard openid sign-in, for the single purpose described below.

What happens to a recording

The video file is opened and decoded in your own browser. It is never uploaded. Still frames sampled from it are sent, over an encrypted connection, to a model provider that reads the names and scores in them. Neither the add-on nor its server keeps the frames or the text after the answer comes back.

What is stored

  • In the spreadsheet: the settings you choose — which tab holds the roster, and the address of the server. Anyone who can open the spreadsheet can see and change these.
  • On the server: nothing. It holds no database and writes no logs of your data. It checks that a request carries a valid Google sign-in token for this add-on, passes the request to the model provider, and returns the answer.
  • Your email address is read from the Google-signed token to decide whether a request is allowed. It is not stored, shared, or used for anything else.

What is never done

Your data is not sold, rented, or shared with anybody. It is not used for advertising. It is not used to train any model. There is no analytics or tracking of any kind in the add-on.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing it

Revoke access at myaccount.google.com/permissions, or delete the script from the spreadsheet's Extensions → Apps Script. Nothing of yours is held anywhere else, so there is nothing else to delete.
