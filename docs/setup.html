Setting it up

Extract Data reads recordings with a model. You bring the model.

The add-on itself installs in one click, but it cannot read a recording until it has somewhere to send the frames. That somewhere is a small service you run — it holds your own model key, so nobody's recordings are ever read on anybody else's account. It is free to run: Cloudflare's free tier covers it, and the model key is yours.

1. Get the code

github.com/kartz-tracking/data-extractor — clone it or download the zip.

2. Deploy the service

With Wrangler installed, from the project folder:

npx wrangler login
npx wrangler deploy

It prints the address it published to — something like https://data-extractor.<you>.workers.dev. Keep it.

3. Give it a model key

A Gemini API key, free from Google AI Studio:

npx wrangler secret put GEMINI_KEY

4. Tell it which add-on may call it

The service answers nobody until it knows. Open a spreadsheet, then Extensions → Extract Data → Extract a recording, press the gear, put in your service's address, and press Save and test. It will refuse — and the refusal contains a client id ending in .apps.googleusercontent.com. Give it that:

npx wrangler secret put SCRIPT_AUD

Press Save and test again; it should name you and the model. That check is what keeps the service yours: it will only answer requests signed by Google for this add-on.

5. Point it at your roster

In the same settings panel, choose the tab holding the list of players. The add-on guesses, and usually guesses right; confirm it once per spreadsheet.

Then

Drop a recording into the window. It is read in your browser, the rows are shown for you to check, and the ones you keep are inserted into the tab you are on — taking their formatting from the row above, leaving every formula and dropdown alone.
